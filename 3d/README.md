# 3D: code and data for the paper

"Threshold, nucleation and disorder pinning in a chiral three-dimensional network of phase links with a conserved budget" (V. Batrukh, 2026). Preprint v1.0: [doi:10.5281/zenodo.24599194](https://doi.org/10.5281/zenodo.24599194). This code (release v3d-1.0): [doi:10.5281/zenodo.24598603](https://doi.org/10.5281/zenodo.24598603).

## Layout
- `lib/` — model library (Python + Numba) as it was used, including the 2D modules that the 3D code imports.
- `runs/rNNN/` — one directory per test cited in the paper as [rNNN]: the criterion written before the runs (`criterion*.txt`), job scripts (`job*.sh`, `jobs*.txt`), analysis scripts (`ana*.py`) and result summaries (`result*.txt`, `ana*.json`). The 3D model is `runs/r351/rq351f.py`; the faster force used for later runs is `runs/r396/fastpatch.py` (checked against the original to machine precision).
- `paper/` — LaTeX source of the preprint and the scripts of its figures (`figs/src/figs3d.py`).
- Shared directories: [r393] is in `r392`, [r355] in `r351/alpha`, [r470G] in `r470g`. Suffixes B, V, G denote sub-tests inside the same directory.

Per-run logs, time series and raw snapshots are not in the repository (size); logs and time series are available from the author on request, snapshots are regenerated by the job scripts.

## Running
Python 3.11+, numpy, scipy, numba, matplotlib. The scripts were run from `/mnt/project-files/model/s52` and use that absolute path; replace it by the location of `3d/lib` and `3d/runs`. Runs are deterministic for a given seed and resume from checkpoints. Comments in the scripts are partly in Ukrainian.
